# Drizzle ORM

We use [Drizzle ORM](https://orm.drizzle.team) with `bun:sqlite` for SQLite access.

## Setup

```ts
import { Database } from "bun:sqlite";
import { drizzle } from "drizzle-orm/bun-sqlite";

const client = new Database(`${deskHome}/desk.db`);
export const db = drizzle({ client });
```

The database path is derived from `DESK_HOME` (defaults to `~/desk/`). This makes it easy to point tests at a temp directory.

The `drizzle-orm/bun-sql` adapter is hardcoded to Postgres dialect; only `bun-sqlite` works for SQLite.

## Schema

Schema is defined in `model/schema.ts` using Drizzle's schema API. See `docs/tech/data-model.md` for the full schema.

## Migrations

Migrations are generated by `drizzle-kit` from the schema and stored in `migrations/`.

```sh
# Generate a new migration after changing model/schema.ts
bunx drizzle-kit generate

# Apply migrations
bunx drizzle-kit migrate
```

### Rules

- Never edit an existing migration file — change the schema and generate a new one.
- Commit migration files alongside the schema changes that require them.
